Excise Duty & Inventory Portal for Wine Importers

A web portal that helps wine importers keep track of their inventory and report the correct excise duty (særavgift) to the Norwegian Tax Administration (Skatteetaten).

The problem

Importers of alcoholic beverages in Norway have to report excise duty correctly and on time. Many handle this manually in spreadsheets, which is time-consuming and makes errors easy to make. Inventory and duty reporting also tend to live in separate places, so it is hard to see what has been imported, sold and reported.

The solution

This portal brings inventory management and excise duty reporting into one place, so importers can:

Keep an up-to-date overview of their wine inventory
Register imports and sales to customers such as bars and restaurants
Get the data they need to report the correct excise duty
Reduce manual work and the risk of reporting errors
Features
Inventory overview: current stock per product, updated as imports and sales are registered
Import and sales registration: keeps a clear record of what comes in and what goes out
Excise duty reporting support: structures the data needed for the excise duty report (særavgiftsmelding)
Tech stack
Frontend: HTML and JavaScript
Database: PostgreSQL (with PL/pgSQL functions)
Built with the help of Claude
